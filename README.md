# DeskMotion

中文 | [English](README.en.md)

macOS 动态壁纸播放器：把视频、图片、GIF 或网页设为桌面壁纸，在桌面图标下方全屏播放。

版本 1.4.1 · 需要 macOS 14 或更新版本 · 支持 Apple 芯片和 Intel 芯片的 Mac

## 安装与首次打开

安装包在下载页 https://deskmotion.jiling.chat/ ，请用 Safari、Chrome 等浏览器下载。给朋友第一次安装时，发这个链接就行（不要用聊天软件转发安装包，原因见常见问题「提示无法打开应用程序」）。

1. 双击 `DeskMotion-1.4.1.dmg`，把 **DeskMotion** 拖到「应用程序」文件夹。
2. 在「应用程序」里双击打开 DeskMotion。
3. 如果系统提示无法打开、或无法验证开发者：
   - 打开「系统设置 → 隐私与安全性」，在页面下方找到 DeskMotion 的提示，点「仍要打开」，输入密码确认；
   - macOS 14 上也可以在「应用程序」里**右键** DeskMotion →「打开」；
   - 只需要操作一次，之后就能正常打开。出现这个提示是因为 DeskMotion 没有经过 Apple 公证（需要付费开发者账号），不代表文件有问题。
   - 如果提示的是「无法打开应用程序“DeskMotion”」（The application can't be opened），并且「隐私与安全性」里没有「仍要打开」，见下方常见问题「提示无法打开应用程序」。
4. DeskMotion 不会常驻 Dock，而是在屏幕顶部菜单栏显示一个小电视图标。第一次打开时会自动弹出「DeskMotion 壁纸库」窗口。

也可以改用安装器版 `DeskMotion-<版本>.pkg`（同样在下载页上）：

- 双击后按提示安装，需要输入管理员密码。它总是安装到「应用程序」文件夹，那里已有同版本或更旧的 DeskMotion 时直接替换（已有更新的版本时保留不动）；正在运行的 DeskMotion 会先退出，装好后自动打开。
- 安装器同样没有 Apple 开发者签名，第一次双击会被拦下：先关掉提示，打开「系统设置 → 隐私与安全性」，在页面下方点「仍要打开」，输入密码确认（macOS 14 上也可以**右键**安装器 →「打开」）。只需要批准这一次，装好的 DeskMotion 不用再批准。

## 使用方法

### 打开壁纸库

点菜单栏的 DeskMotion 图标 →「打开壁纸库」。壁纸库或设置窗口开着的时候，Dock 里会临时出现 DeskMotion 图标，也能用 ⌘H、⌘W、⌘Q 等快捷键；窗口都关掉后图标会自动消失。

### 导入壁纸

- 把文件或文件夹**拖进壁纸库窗口**，或者点工具栏的「导入文件…」。
- 在线网页：点「添加网址…」，输入以 `http://` 或 `https://` 开头的网址。
- 导入时文件会**复制**进壁纸库，之后移动或删除原文件都不受影响。
- 需要转码的视频会在窗口底部显示进度，转码期间可以点「取消导入」。

### 设置壁纸

- **双击**壁纸卡片：设为当前选中的显示器的壁纸。在右侧「显示器」面板里点一下，可以切换选中的显示器。
- **右键**壁纸卡片：「设为「某显示器」的壁纸」「应用到所有显示器」「在 Finder 中显示」「重命名…」「删除…」。
- 每个显示器可以单独设置：
  - **缩放方式**：填充（默认，铺满屏幕并裁掉多余部分）、适应（完整显示，两侧留黑边）、拉伸、居中（按原始尺寸显示）。网页壁纸由网页自己排版，不受这个设置影响。
  - **静音**和**音量**（视频和网页壁纸）。
  - **清除壁纸**：恢复成系统壁纸。
- 插拔显示器后，每块屏幕会自动恢复各自的设置。
- 第一次接上的显示器会显示和主显示器一样的壁纸或播放列表，缩放方式也一样，默认静音；之后可以在「显示器」面板里单独修改。主显示器没有壁纸时，照其他有壁纸的显示器设；合上盖子只用外接显示器时，第一次接上的显示器没有可以照着设的，要自己在面板里选。以前接过的显示器照旧恢复它的设置；以前的版本没给它放壁纸、你也没设过的显示器，更新到 1.4 后下次接上时也照主显示器设好（当时是有意清除的话，再清除一次即可，之后不会再变）。

### 播放列表与自动轮换

把几张壁纸放进一个播放列表，可以让它们自动轮换。

- **新建**：壁纸库窗口顶部切到「播放列表」，点「新建」；或在壁纸卡片上右键 →「添加到播放列表」→「新建播放列表…」。
- **添加和排序**：在列表里点「添加壁纸…」多选，或在壁纸卡片上右键 →「添加到播放列表」。拖动缩略图可以调整顺序。
- **切换方式**（每个列表单独设置）：
  - **定时轮换**：切换间隔可选 1 分钟到 24 小时；播放顺序可选顺序或随机（随机时一轮内每张都轮到一次）。
    - 「视频播完一遍再切」：轮到视频时，等它完整播完一遍再换。
    - 「解锁或开机时换一张」：每次解锁屏幕、或启动 DeskMotion 时换到下一张。
  - **按时段**：早上、白天、傍晚、夜里各选一张，开始时间可以调整，到点自动切换。
- **多块屏幕**用同一个列表时，可选「同步切换（所有屏幕同一张）」或「各屏独立」。
- **用到显示器上**：右侧「显示器」面板把「内容」切到「播放列表」并选择列表；或在播放列表页右键 →「设为「某显示器」的播放列表」。
- 面板里会显示当前是哪一张、下次什么时候切换，还可以点「下一张」；菜单栏里也有「下一张壁纸」。
- 轮换按真实时间进行：壁纸暂停期间（用电池、锁屏等）到点也会切换，重启 DeskMotion 后从原来的进度继续。

### 声音

视频和网页壁纸默认播放声音，但**只有主显示器默认出声**，其他显示器默认静音，避免几路声音混在一起；新接上、照别的显示器设好的显示器也默认静音，哪怕它成了主显示器。菜单栏里的「全部静音」可以一键静音所有壁纸。

### 暂停与自动暂停

- 菜单栏 →「暂停播放」可以手动暂停全部壁纸，再点「继续播放」恢复。
- 下面几种情况会自动暂停，节省电量和性能。每一项都可以在菜单栏 →「设置…」→「自动暂停」里单独关闭：
  - 全屏应用挡住桌面时（只暂停被挡住的那块屏幕）
  - 最大化的窗口挡住桌面时（见下方说明）
  - 使用电池供电时
  - 锁屏或屏幕休眠时（只暂停桌面上的播放；锁屏界面由系统绘制，要在锁屏上播放请打开下面的「锁屏播放动态壁纸」，需要 macOS 26 或更高版本）
  - 低电量模式开启时
  - Mac 过热时（系统报告发热严重、开始降频时暂停全部壁纸，温度恢复后自动继续）
- 「最大化的窗口挡住桌面时」：某个窗口铺满了这块屏幕除菜单栏和程序坞以外的区域（平铺窗口时留的小缝也算），就暂停这块屏幕的壁纸。它和「全屏应用挡住桌面时」互不影响：关掉全屏那一项后，全屏应用不会因为这一项而暂停壁纸。
  - 例外：程序坞设成自动隐藏或放在另一块屏幕上时，铺满的窗口和全屏应用大小完全一样，会被当成全屏应用；菜单栏设成全屏时也显示时，全屏应用会被当成铺满的窗口。
- 自动暂停时，菜单栏菜单里会显示「已暂停：」和原因。

### 开机自动启动

菜单栏 →「设置…」→ 打开「开机时自动启动」。登录后 DeskMotion 会自动启动，并恢复上次的壁纸。

### 界面语言

DeskMotion 有简体中文和英文界面。默认跟随系统：「系统设置 → 通用 → 语言与地区」的首选语言里，简体中文排在英文前面就显示中文，否则显示英文。

想单独指定的话，菜单栏 →「设置…」→「通用」→「语言」选「简体中文」或「English」，然后点「立即重新打开」（DeskMotion 会退出并自动重新打开），或者等下次打开时生效。在「系统设置 → 通用 → 语言与地区」里给 DeskMotion 单独设语言也一样，两处是同一个设置。

### 同步到系统壁纸

默认开启（菜单栏 →「设置…」→「同步到系统壁纸」）。DeskMotion 会把当前壁纸的一帧设为 macOS 的系统壁纸，这样锁屏、调度中心和菜单栏的配色都和桌面一致：

- 视频取开头附近的一帧，GIF 取第一帧，网页取加载完成后的画面，动态播放的场景取当时的画面，图片用原图；按该显示器的缩放方式生成。同一张壁纸、同样的设置再次同步时直接用上次的画面。
- 关闭这个开关、清除某块屏的壁纸、或退出 DeskMotion 时，会恢复你原来的系统壁纸。如果期间你在系统设置里换了别的壁纸，不会覆盖你的选择。
- macOS 26 上，如果原来的壁纸是航拍等动态壁纸，或者其他桌面空间显示着同步的画面，关闭或退出时 DeskMotion 会直接改写系统的壁纸设置，并重启一次系统壁纸服务（桌面会短暂闪一下），每个空间、每块显示器都恢复成原来的样子，航拍照样会动。注销或关机时不重启系统壁纸服务：原来是图片的只恢复当前空间，原来是航拍等动态壁纸的先留着同步的画面（这时恢复只能变成静态图片），其余的之后补上（同步关着时在下次打开 DeskMotion 时，开着时在下次关闭或退出时）。
- 以前的版本可能在其他桌面空间里留下了同步用的画面。macOS 26 上，「设置…」里会出现「把其他桌面空间里遗留的 DeskMotion 静帧换回当前系统壁纸」，点「换回」就会换成系统设置里当前的壁纸。
- 已知限制（macOS 26 以外的版本）：
  - macOS 只允许修改当前桌面空间的系统壁纸，DeskMotion 会在你切换到其他空间时补设；退出时只能恢复当前空间。
  - 如果原来的系统壁纸是 macOS 的动态"航拍"壁纸，系统只提供它的静态图片，恢复后会变成静态版本。需要动态效果的话，在「系统设置 → 墙纸」里重新选一次即可。

### 锁屏播放动态壁纸（macOS 26 及以上）

锁屏画面由 macOS 自己绘制，DeskMotion 的窗口锁屏时看不见，所以平时锁屏上只有「同步到系统壁纸」设的那张静止画面。在 macOS 26 及以上，DeskMotion 可以作为一个系统壁纸，让视频壁纸在锁屏上播放（也可以在屏幕保护程序里播放）：

1. 菜单栏 →「设置…」→「锁屏」，打开「锁屏播放动态壁纸」。
2. DeskMotion 会自动把自己设为每个桌面空间、每块显示器的系统壁纸，不用去系统设置。这时系统壁纸服务会重启一下，桌面短暂闪烁；「锁屏」下面显示「已生效」就好了。原来的屏幕保护程序不变。
3. （可选）想让屏幕保护程序也播放：在「系统设置 → 屏幕保护程序」里选「DeskMotion」。

如果没能自动设置（比如系统壁纸服务没有接受，或者 macOS 版本还没验证过），DeskMotion 会打开「系统设置 → 墙纸」，并在它上面浮出一个小提示告诉你怎么选：往下找到「DeskMotion」一栏，点其中的「DeskMotion」。选好后提示自动关闭；能写系统壁纸设置时，DeskMotion 接着把其余显示器和桌面空间也设好（系统壁纸服务再重启一次），不能时每块显示器各选一次，再切到每个空间各选一次。

之后：
- 视频壁纸（包括已「转换为视频」的动图）在锁屏（以及选了 DeskMotion 的屏幕保护程序）里循环播放；图片、动图、网页和场景显示静止画面。每块显示器各放各的。
- 桌面上照旧是 DeskMotion 自己在播放；退出 DeskMotion 后，桌面显示一张静止画面，锁屏仍然播放。
- 「同步到系统壁纸」开着也没关系：锁屏播放开着时它暂停，不会把系统壁纸换回静止画面；同步设过的画面在 DeskMotion 设置自己时一起换掉，关闭时换回的是同步之前你原来的壁纸。
- 「暂停播放」，以及开着的「使用电池供电时」「低电量模式开启时」「Mac 过热时」自动暂停，同样让锁屏只显示静止画面。
- 想停用：关掉「锁屏播放动态壁纸」，DeskMotion 会把每个空间、每块显示器换回原来的壁纸（系统壁纸服务再重启一次）；屏幕保护程序不变。DeskMotion 没能自动设置、是你在系统设置里手动选的，有时换不回（比如 macOS 版本还没验证过）：这时 DeskMotion 会提示你在「系统设置 → 墙纸」里换一张别的。
- 在「系统设置 → 墙纸」里换了别的壁纸时（关掉「在所有空间中显示」再选的也算），DeskMotion 不和你抢：自动关闭「锁屏播放动态壁纸」（开着的话也关闭「同步到系统壁纸」，免得它把静止画面盖到你选的壁纸上），「设置…」→「锁屏」里会说明一次。你没换的那些桌面空间仍显示 DeskMotion 的静止画面，到那个空间再选一次即可；或者再打开、关闭一次「锁屏播放动态壁纸」，那些空间会换回原来的壁纸，你选的保留。只有某个空间（比如全屏应用所在的空间）的壁纸被别的 App 改了时不算你换了壁纸：「锁屏播放动态壁纸」不会关闭，下次打开 DeskMotion 时把那里改回 DeskMotion。
- 全屏应用所在的空间有自己的壁纸设置，在系统设置里选壁纸时改不到它们。DeskMotion 打开时如果发现有空间（包括全屏应用的）或显示器不是 DeskMotion，会自动把它们也设好（系统壁纸服务重启一次，桌面闪一下）；都设好了就什么都不改。

已知限制：
- 锁屏后显示器通常 30 秒到 1 分钟就会熄灭，所以能看到的主要是锁屏后、唤醒后的一小段。
- 这用到了 macOS 未公开的接口，macOS 大版本更新后可能失效（锁屏变成静止画面或黑屏），到时在「系统设置 → 墙纸」里换回别的壁纸即可，并留意 DeskMotion 的更新。
- 开机时 FileVault 的登录界面不在范围内；macOS 14 和 15 不支持（开关是灰的）。
- 带旋转标记的视频（比如手机竖拍）在锁屏上按原始方向显示。

### 网页壁纸与鼠标

网页壁纸只跟随鼠标移动，可以做视差、跟随之类的效果；它不接收点击，所以网页里的按钮和链接点不到，点击桌面和桌面图标都照常可用。

### Wallpaper Engine 壁纸

DeskMotion 可以直接导入 Wallpaper Engine 的视频壁纸、网页壁纸和场景（scene）壁纸；场景壁纸在给了 Wallpaper Engine 的素材之后动态播放（预览：还有一些内容画不出来，见下），否则显示静止的画面：

- **导入项目文件夹**：把含有 `project.json` 的项目文件夹拖进壁纸库（或用「导入文件…」选择）。视频类导入其中的视频（需要时照常转码），网页类按网页壁纸导入，场景类见下；壁纸名用项目标题，缩略图用项目预览图（场景类用导入的画面）。
- **批量导入创意工坊**：把下面有很多项目子文件夹的目录（比如 Steam 创意工坊的内容目录）拖进来，会一次导入其中所有视频类、网页类和场景类项目，跳过不支持的；全部完成后弹窗告诉你导入了多少个、跳过了哪些以及原因。
- **场景（scene）壁纸**：导入时 DeskMotion 把场景里的各个图层（图片、纯色和木偶图层）按顺序叠成一张静止的画面，算上它们的颜色、透明度、着色和遮罩，作为静态图片壁纸导入；场景只有一段视频的，导入成视频壁纸。没有动态播放时，壁纸卡片和显示器面板上标有「静态」：特效、粒子、文字、动画以及跟随鼠标和声音的效果都没有。动态播放见下面的「动态播放场景（预览）」。
  - 合成不出可用的画面时（比如画面主要由粒子、特效、文字或视频组成，或者贴图格式不认识），改用项目的预览图；连预览图也没有，就导入失败并提示「这个场景没有可显示的背景画面」。
  - 也可以直接把单独的 `scene.pkg` 文件拖进来。不是 Wallpaper Engine 打包文件的 .pkg（比如 macOS 的安装包）会提示「这不是 Wallpaper Engine 的 scene.pkg」。
  - 原始的场景文件（project.json、scene.pkg 和预览图）会一起保存在壁纸库里，动态播放时用的就是它们。
  - 动态播放还画不出来的内容（比如时钟等文字、场景里的视频），可以在 Windows 上录成视频再导入，见常见问题「场景（scene）壁纸怎样才能动起来」。
- **动态播放场景（预览）**：DeskMotion 用自己的引擎实时渲染场景壁纸，需要 Wallpaper Engine 自带的素材文件夹 `assets`（场景共用的着色器、材质和特效，DeskMotion 不附带）。
  - 在装有 Wallpaper Engine 的 Windows 电脑上，它在 Steam 库的 `steamapps\common\wallpaper_engine\assets`（在 Steam 里右键 Wallpaper Engine →「管理」→「浏览本地文件」可以打开 `wallpaper_engine` 文件夹）。把整个 `assets` 文件夹（约 80 MB）复制到这台 Mac（U 盘、网盘、局域网共享都可以）。
  - 菜单栏 →「设置…」→「Wallpaper Engine 场景」→「Wallpaper Engine 素材」点「选择…」，选中 `assets` 文件夹（选包含它的 `wallpaper_engine` 或 Steam 的 `common` 文件夹也可以）。DeskMotion 会把它复制进自己的数据文件夹（`~/Library/Application Support/DeskMotion`），显示「已就绪」和大小，之后原来的文件夹可以删掉；选的不是素材文件夹（或者只复制了一部分）会提示该选哪个。「移除…」确认后删掉这份副本。
  - 素材就绪后，场景壁纸就动态播放，卡片上的「静态」变成「动态」。不想动态播放的话，关掉同一处的「动态播放场景壁纸（预览）」（默认开启），场景就显示导入时的静止画面。
  - 现在能画出来的：场景的图片、纯色和木偶图层（木偶是静止姿态），用场景自己的着色器，随时间变化的材质（比如水流）会动；特效（比如模糊、水波、晃动、着色、遮罩）、合成图层和混合模式；粒子（比如雨、雪、雾、火花、星星，包括跟随鼠标和跟随声音的）；泛光、镜头晃动、跟随鼠标的相机视差、时间线（关键帧）动画和精灵动画；跟随声音的特效（比如音频条，见下面的「音频律动」）。最高 30 帧/秒，画面不随时间变的场景画好后就停下，鼠标、声音或参数变了才再画（粒子一直在动的场景每帧都画）；自动暂停（全屏、电池、锁屏等）同样适用。还不支持的：文字（包括时钟和日期）、场景里的视频和声音、脚本（由脚本控制的部分停在初始状态，个别由脚本控制的特效不画）、木偶的骨骼动画、灯光；粒子里少数不常用的功能（比如碰撞）还没做，有的粒子效果和 Wallpaper Engine 里的疏密、大小、亮度不完全一样。所以有的场景动态播放时和 Wallpaper Engine 里差别较大（比如缺了时钟）；后续版本会逐步补上。
  - 只导入成视频的场景（场景只有一段视频）仍按视频播放。
  - 场景加载失败、里面没有能画出来的内容、显卡出错或太慢、或者所有动态播放的场景加起来占的显卡内存超过上限（显卡建议用量的一半）时，自动改回静止画面（Mac 睡眠醒来后、下次打开 DeskMotion 或重新选择素材后再试）。
- 其他类型（比如应用程序类）暂不支持。
- **壁纸参数**：网页壁纸和动态播放的场景如果带有可调参数（滑块、颜色、开关、下拉选项、文本），在壁纸卡片上右键 →「壁纸参数…」调整。改动立即生效并自动保存，「恢复默认」可以还原。
- **音频律动**：支持音频律动的网页壁纸，和带有跟随声音的特效或粒子的动态场景（比如音频条），会跟着电脑正在播放的声音跳动。场景要不要声音，看它画出来的部分（包括能在「壁纸参数…」里打开的）用不用得到，用不到的场景不采集声音。
  - 第一次用到时，macOS 会请求「录制系统音频」的权限，DeskMotion 只用它让壁纸跟着声音跳动。拒绝的话壁纸照常显示，只是不会跳动。
  - 需要 macOS 14.2 或更新版本（网页壁纸和场景都是）。
  - 网页壁纸只有本地的（导入的网页文件、文件夹、zip）可以使用，在线网址壁纸不行。
  - 只在壁纸显示着且没有暂停时采集声音（锁屏、屏幕休眠时不采集）。

### 检查更新与自动更新

- DeskMotion 启动时和之后每天自动检查一次有没有新版本（先查国内的下载页，查不到再查 GitHub），不会自动下载，也不会自己弹出窗口。不需要的话，在「设置…」→「通用」里关掉「自动检查更新」。也可以随时点菜单栏 →「检查更新…」。
- 有新版本时，菜单栏图标右上角会出现一个小红点，并收到一条「DeskMotion x.y.z 可用」的系统通知（每个新版本只通知一次；第一次会询问是否允许 DeskMotion 发送通知，不允许也不影响红点），菜单栏菜单顶部会出现「有新版本 x.y.z…」。点通知或这个菜单项，在「DeskMotion 更新」窗口里能看到更新说明（看过之后红点消失），点「立即更新」：DeskMotion 会下载新版本（显示进度，可以取消）、校验签名，然后自动退出、替换并重新打开。任何一步出错都会提示原因，旧版本照常使用。
- 如果 DeskMotion 不在能直接替换的位置（比如直接在安装包或「下载」文件夹里打开、或者没有写入权限），按钮会变成「前往下载页」，在浏览器里下载新的安装包重新安装即可。所以请把 DeskMotion 放在「应用程序」文件夹里使用。
- 正在导入壁纸时不能更新，等导入完成后再点「立即更新」。
- 已知限制：DeskMotion 没有经过 Apple 公证，每次更新后系统会把它当成一个新的 App，用到音频律动时「录制系统音频」的权限需要重新允许一次。

## 支持的格式

| 类型 | 格式 | 说明 |
|---|---|---|
| 视频（直接播放） | mp4、m4v、mov | 使用系统硬件解码，最省电 |
| 视频（导入时自动转码） | webm、mkv、avi、flv、wmv、ogv、ogg、mpg、mpeg、ts、m2ts、mts、3gp、asf | 导入时转成 mp4（HEVC 编码），之后和普通视频一样播放 |
| 图片 | jpg、jpeg、png、heic、heif、webp、tiff、tif、bmp | 按照片记录的方向自动转正 |
| 动图 | gif、动态 webp、apng（扩展名 .png 或 .apng） | 按每一帧自带的时长播放；大动图导入时自动转成视频（见下方补充说明） |
| 网页 | 含 index.html 的文件夹、单个 .html / .htm 文件、.zip 压缩包、http / https 网址 | 兼容 Wallpaper Engine 网页壁纸（会读取 project.json 指定的入口） |
| Wallpaper Engine 项目 | 含 project.json 的项目文件夹、创意工坊文件夹（批量导入）、单独的 scene.pkg | 支持视频类、网页类和场景类；场景类给了 Wallpaper Engine 的素材后动态播放（预览），否则显示各图层合成的静止画面（静态），见上方「Wallpaper Engine 壁纸」 |

补充说明：

- mp4 / mov 文件如果系统不能直接播放（比如里面是 VP9 编码），会自动改为转码。
- AV1 编码的视频需要 M3 或更新芯片的 Mac 才能转码，更早的 Mac 会提示「此 Mac 不支持 AV1 视频解码」。
- 视频只取第一条画面和第一条音轨；如果音轨无法解码，会只保留画面。
- webp 和 png 文件导入时会检查帧数：多帧的（动态 WebP、APNG）按动图导入，和 GIF 一样播放；单帧的按图片导入。
- 大动图（GIF、动态 WebP 或 APNG，解码后超过 150 MB，例如 1080p、几十帧）导入时会转成视频（HEVC 编码），壁纸库里只保留转好的视频。窗口底部显示「正在转码」的进度，可以取消。画面和每一帧的时长都不变，透明的部分显示为黑色。
- 以前导入的大动图（GIF，以及 1.3 之前按静态图片导入、DeskMotion 启动时会自动识别为动图的动态 WebP / APNG）：在壁纸卡片上右键 →「转换为视频（更省电）」（只有大动图才有这一项），确认后在窗口底部转换。转换后名字、缩略图、在各显示器和播放列表里的位置都不变；失败或取消时保持原样。
- Steam 创意工坊的场景（scene）壁纸和 scene.pkg 要有 Wallpaper Engine 的素材才能动态播放（预览），文字和时钟、脚本、场景里的声音和视频暂不支持；没有素材时只显示静止的画面（见上方「Wallpaper Engine 壁纸」）。其他 .pkg 文件（比如 macOS 安装包）不能导入。

## 资源占用

在 MacBook Pro 14 英寸（M5 Max，内置屏 3024×1964）上实测，一块屏幕播放一张壁纸时的稳定值。CPU 按单个核心计，100% 表示占满一个核心：

| 壁纸 | CPU | 内存 |
|---|---|---|
| 4K 视频 | 约 9%（DeskMotion 约 5%，系统硬件解码约 4%） | DeskMotion 约 90 MB，系统解码服务另占约 350 MB 画面缓冲 |
| 网页（全屏粒子动画，60 帧/秒） | 约 32%（大部分在网页进程） | 网页进程约 320 MB |
| 大 GIF（1080p，60 帧），导入时转成视频后 | 约 3%（DeskMotion 约 2%，系统硬件解码约 1%） | DeskMotion 约 80 MB，系统解码服务约 40 MB |
| 同一个 GIF 不转换、边播边解码（1.2 及以前） | 约 36% | 约 400 MB |
| 4K 图片 | 几乎为 0 | — |
| Wallpaper Engine 场景（动态播放，30 帧/秒） | 画面不动的不到 1%；动画场景约 1–14%，取决于场景 | 约 400 MB–1.8 GB，取决于场景的贴图和特效 |
| 暂停 | 0 | DeskMotion 约 160 MB |

- 视频用系统硬件解码，是最省电的格式；网页壁纸的占用取决于网页本身。
- 场景的数字是用 31 个创意工坊场景在测试程序里离屏测的（没有窗口合成），不是在 App 里；显卡每帧 0.04–4 毫秒。画面不随时间变的场景画好就停下，鼠标、声音或参数变了才再画，几乎不占 CPU；只有图片和简单材质的动画场景约 1–3%；特效多（每帧要画几十个步骤）或粒子多（每帧在处理器上算几千到几万个粒子）的场景高一些，实测 4–14%；有一直在动的粒子的场景每帧都画，不会停下。CPU 占比随处理器当时的频率浮动，同一个场景两次测量可能差一倍。贴图多的场景内存占用大，两块屏幕显示同一个场景时各占一份；暂停时场景的贴图仍然留在内存里（上表「暂停」一行不含它们）。
- GIF 解码后的总大小在 150 MB 以内（例如 720p、几十帧）时会一次解码好缓存起来，播放几乎不占 CPU；更大的 GIF 只能边播边解码，CPU 占用较高，所以导入时会自动转成视频，和视频壁纸一样省电（见上表）。动态 WebP 和 APNG 也一样。以前导入的大 GIF 可以在壁纸卡片上右键 →「转换为视频（更省电）」。
- 自动暂停（用电池、全屏、锁屏等）时几乎不占 CPU。开着「锁屏播放动态壁纸」时，锁屏期间由系统壁纸扩展用硬件解码视频，显示器熄灭后停止。

## 卸载

1. 如果开过「开机时自动启动」，先在「设置…」里关掉（也可以在「系统设置 → 通用 → 登录项」里移除）。
2. 如果开着「锁屏播放动态壁纸」，先在「设置…」→「锁屏」里关掉，原来的系统壁纸会换回来；如果是在「系统设置 → 墙纸」里手动选的 DeskMotion，先在那里换一张别的壁纸。
3. 菜单栏 →「退出 DeskMotion」。退出时会恢复原来的系统壁纸（开着「同步到系统壁纸」时）。
4. 把「应用程序」里的 DeskMotion 拖到废纸篓。
   - 用安装器（.pkg）安装的也是这样删除。之后还可以在「终端」里运行 `sudo pkgutil --forget io.github.kevinnb66699.DeskMotion.pkg`（需要输入管理员密码），清掉系统里的安装记录；不运行也没关系。
5. 如果要连同导入的壁纸一起删除，在 Finder 里按 ⇧⌘G，依次前往并删除下面这些位置：
   - `~/Library/Application Support/DeskMotion`（壁纸库、播放列表、壁纸参数、Wallpaper Engine 素材的副本、同步用的系统壁纸画面、锁屏用的静止画面和系统壁纸设置的备份）
   - `~/Library/Containers/io.github.kevinnb66699.DeskMotion.WallpaperExtension`（锁屏用的系统壁纸扩展自己的文件夹，macOS 26 上扩展运行过才会有）
   - `~/Library/Preferences/io.github.kevinnb66699.DeskMotion.plist`（窗口位置、界面语言等偏好）
   - `~/Library/Caches/` 和 `~/Library/WebKit/` 下名为 `io.github.kevinnb66699.DeskMotion` 的文件夹（网页壁纸的缓存）
   - `~/Library/Logs/DeskMotion`（自动更新的日志）

## 常见问题

**提示无法打开应用程序，也没有「仍要打开」**
多半是安装包通过飞书等聊天软件转发过：这类软件保存的文件会带上更严格的隔离标记，macOS 会直接拒绝运行，不给「仍要打开」的选项。任选一种办法：
- 用浏览器（Safari、Chrome 等）从下载页 https://deskmotion.jiling.chat/ 重新下载安装包（备用：https://github.com/Kevinnb66699/DeskMotion/releases/latest ），按「安装与首次打开」的步骤安装；
- 或者先把 DeskMotion 拖进「应用程序」，再打开「终端」，粘贴下面这行并回车，之后就能直接双击打开：
  ```
  xattr -dr com.apple.quarantine /Applications/DeskMotion.app
  ```

**壁纸停住不动了**
打开菜单栏的 DeskMotion 菜单，看有没有「已暂停：」。多半是触发了自动暂停（用电池、低电量模式、Mac 过热、全屏应用、铺满屏幕的窗口等）。可以在「设置…」里关掉对应的自动暂停，或者点「继续播放」。

**合上盖子再打开后，桌面是黑的**
Mac 睡眠（合盖、显示器熄灭）后醒来时，DeskMotion 会把每块屏幕的壁纸重新加载一次（需要密码时在解锁后）：视频从头播放，网页壁纸重新打开，画面淡入；用电池等自动暂停时保持暂停，显示第一帧。视频播放出错会自动重试几次。
1.3.0 及更早的版本没有这一步，睡眠后壁纸有时会一直是黑的。不用重启 DeskMotion，可以先试：在壁纸库里换一张别的壁纸再换回来；用电池时插上电源（或者在「设置…」里关掉「使用电池供电时」暂停）。都不行再退出、重新打开 DeskMotion。
装了清理、省电或者「冻结后台应用」一类的工具时，它们可能把 DeskMotion 挂起，请把 DeskMotion 加进这类工具的例外（白名单）。
新版本也遇到黑屏的话，请在重启 DeskMotion 之前打开「终端」，粘贴下面这行并回车，反馈时附上桌面上的 `deskmotion-log.txt`：
```
/usr/bin/log show --last 3h --predicate 'subsystem == "io.github.kevinnb66699.DeskMotion"' > ~/Desktop/deskmotion-log.txt
```

**没有声音**
只有主显示器默认出声。检查壁纸库右侧该显示器的「静音」开关和「音量」，以及菜单栏里是否开着「全部静音」。图片和 GIF 壁纸本身没有声音。

**导入失败**
壁纸库窗口底部的任务条会写明原因，例如不支持的文件类型、没有找到网页入口文件（index.html）、此 Mac 不支持 AV1 视频解码。

**网址壁纸一片空白**
先确认这个网址在浏览器里能打开。开机时如果网络还没连上，DeskMotion 会自动重试。

**锁屏或调度中心里的壁纸和桌面不一样**
确认「设置…」里开着「同步到系统壁纸」。macOS 只能修改当前桌面空间的系统壁纸，其他空间会在你切换过去时补上。

**锁屏还是静止画面，或者是黑的**
- 确认系统是 macOS 26 或更高版本，「设置…」→「锁屏」里开着「锁屏播放动态壁纸」，并且下面显示「已生效」。显示「DeskMotion 还不是系统壁纸」时，点「自动设置」；显示「需要在系统设置里选择 DeskMotion」时，点「打开墙纸设置」照提示选一次。
- 从某个全屏应用锁屏时显示的是别的壁纸，或者新建的桌面空间、新接的显示器还是原来的壁纸：退出再打开一次 DeskMotion，它会在启动时把这些也设成 DeskMotion；或者关掉再打开一次「锁屏播放动态壁纸」。
- 只有视频壁纸在锁屏上播放；暂停播放、用电池、低电量模式、Mac 过热（对应的自动暂停开着时）也只显示静止画面。
- 黑屏：多半是先在系统设置里选了 DeskMotion、后打开的开关，或者 DeskMotion 在这块屏上没有壁纸。打开开关、设好壁纸后稍等几秒。
- 还是不行的话，看 `~/Library/Application Support/DeskMotion/WallpaperExtension/state.json`：`lastError` 写着扩展最近遇到的问题，反馈时请附上它；`safeMode` 是 `true` 表示扩展 10 分钟内意外退出了 3 次，暂时只显示静止画面，最迟 10 分钟后自动恢复（开关「锁屏播放动态壁纸」、注销、更新 DeskMotion 时扩展的重启不算意外退出）。

**「系统设置 → 墙纸」里找不到 DeskMotion**
需要 macOS 26 或更高版本。把 DeskMotion 放进「应用程序」文件夹并打开一次，再重新打开「系统设置」；还是没有的话，注销后重新登录。

**关掉同步后，系统壁纸不再是动态的**
macOS 26 以外的版本上，原来的动态"航拍"壁纸只能以静态图片恢复（系统限制），在「系统设置 → 墙纸」里重新选一次即可。macOS 26 上会恢复成原来的航拍；如果当时系统壁纸服务没能接受，当前空间会恢复成静态图片，其他空间之后再试（同步关着时在下次打开 DeskMotion 时，开着时在下次关闭或退出时；连续两次都没接受就不再自动重试，改由「设置…」里的「换回」来做）；要让当前空间重新动起来，在「系统设置 → 墙纸」里重新选一次。

**音频律动的壁纸不跳动**
确认这是导入到本地的网页壁纸（在线网址壁纸不能用音频律动），或者是标着「动态」、带有跟随声音的特效或粒子的场景，系统是 macOS 14.2 或更新版本、电脑正在播放声音，并且允许了「录制系统音频」的权限。更新 DeskMotion 后需要重新允许一次。

**网页壁纸里的按钮点不了**
这是正常的：网页壁纸只跟随鼠标移动，不接收点击，点击桌面和桌面图标照常可用。

**场景（scene）壁纸怎样才能动起来**
场景壁纸（创意工坊里带 scene.pkg 的那些）不是视频，而是实时渲染出来的：图层要用场景自己的着色器画，很多还要用到 Wallpaper Engine 安装目录里的公共素材（`assets` 文件夹），而这些素材 DeskMotion 不能附带。所以要动态播放，需要你从装有 Wallpaper Engine 的 Windows 电脑上把 `steamapps\common\wallpaper_engine\assets` 复制过来，在「设置…」→「Wallpaper Engine 场景」里选择它，步骤见上方「动态播放场景（预览）」。没有素材时场景显示导入时合成的静止画面（卡片上标有「静态」）。
已经标着「动态」却看起来不太动、或者缺了主要内容：动态播放还是预览，DeskMotion 的引擎还不支持文字（包括时钟）、场景里的视频和声音、脚本和木偶的骨骼动画，这类场景暂时和 Wallpaper Engine 里差别较大。想要完全一样的效果，变通办法（也是 Wallpaper Engine 官方推荐的导出方式）：在 Windows 电脑上用 Wallpaper Engine 以窗口模式播放这张壁纸，用录屏软件（比如 OBS）录成 mp4，再把视频导入 DeskMotion。录成视频后它就是一张普通的视频壁纸，不会再跟随鼠标、声音变化，也不能调参数。
场景显示「静态」而素材已经就绪：确认「动态播放场景壁纸（预览）」开着；只有一段视频的场景按视频播放；加载失败、没有能画出来的内容（比如只有文字）、显卡太慢或显卡内存不够的场景会改回静止画面，Mac 睡眠醒来后、下次打开 DeskMotion 或重新选择素材后再试。

**更新失败，或「立即更新」变成了「前往下载页」**
「DeskMotion 更新」窗口会写明原因，旧版本不受影响，可以点「重试」，或点「前往下载页」下载安装包重新安装。如果按钮一开始就是「前往下载页」，多半是 DeskMotion 不在「应用程序」文件夹里（比如直接在安装包里打开的），先把它拖进「应用程序」再从那里打开。

**播放列表没有切换**
看显示器面板里的「下次切换」时间。开了「视频播完一遍再切」时，正在播放的视频要播完才会换；列表里只有一张可用的壁纸时不会切换。

**按 ⌘H 后壁纸还在**
这是正常的：隐藏 DeskMotion 只会隐藏壁纸库窗口，不影响桌面壁纸。

**耗电**
视频壁纸使用硬件解码，用电池时默认自动暂停。网页壁纸的耗电取决于网页本身，复杂的 3D 网页会更耗电。
